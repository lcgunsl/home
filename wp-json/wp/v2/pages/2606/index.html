Pol\u00edticas de Privacidad<\/strong><\/h4>\n

El Laboratorio de Computaci\u00f3n Gr\u00e1fica (LCG) proporciona esta Pol\u00edtica de Privacidad para ayudar a explicar nuestras pr\u00e1cticas de recopilaci\u00f3n de informaci\u00f3n en nuestras aplicaciones para dispositivos m\u00f3viles. Esta Pol\u00edtica de Privacidad se emplea en todas nuestras aplicaciones a menos que se indique lo contrario.<\/p>\n

Nuestras aplicaciones para dispositivos m\u00f3viles no tienen un costo para su descarga o uso.<\/p>\n

\u00bfQu\u00e9 informaci\u00f3n obtiene la aplicaci\u00f3n y c\u00f3mo se utiliza?<\/p>\n

Las aplicaciones con tecnolog\u00eda de Realidad Aumentada requieren el uso de la c\u00e1mara del dispositivo para reconocer los diferentes marcadores, y as\u00ed poder cargar el contenido virtual (sea video, im\u00e1genes, modelos 3D, audio, etc.). Por esto se solicita el permiso de \u201cUso de la c\u00e1mara\u201d en las aplicaciones.<\/p>\n

Retenci\u00f3n de datos<\/p>\n

Las aplicaciones\u00a0no recolectan ni mantienen\u00a0informaci\u00f3n confidencial ni personal como pueden ser el ID del tel\u00e9fono, contactos, contrase\u00f1as ni ubicaci\u00f3n entre otras. Cuando alguna de nuestras aplicaciones tenga la funci\u00f3n de realizar capturas de pantalla o tomar fotograf\u00edas estas ser\u00e1n almacenadas en el dispositivo del usuario (es decir, de forma local) sin que el Laboratorio de Computaci\u00f3n Gr\u00e1fica tenga acceso a ellas, en consecuencia no se env\u00eda esta informaci\u00f3n a nuestros servidores. Por estas razones, el Laboratorio de Computaci\u00f3n Gr\u00e1fica no tiene las facultades de distribuir datos personales de los usuarios que hacen uso de sus aplicaciones.<\/p>\n

Cambios<\/p>\n

Esta Pol\u00edtica de Privacidad puede ser actualizada sin previo aviso. Se recomienda revisar esta p\u00e1gina peri\u00f3dicamente para comprobar alg\u00fan cambio. Al utilizar nuestras aplicaciones se considera que el usuario conoce y acepta nuestra Pol\u00edtica de Privacidad, el uso continuo se considera la aprobaci\u00f3n de todos los cambios. Estos cambios son efectivos inmediatamente despu\u00e9s de su publicaci\u00f3n en esta p\u00e1gina.<\/p>\n
